## S10 IMSS codebook access and unresolved field semantics

The existing project metric contract cites **Guía del usuario datos abiertos,
asegurados** ([official link](https://datos.imss.gob.mx/sites/default/files/Guia_usuario_datos_abiertos_asegurados.pdf))
and **Glosario de datos abiertos, asegurados**
([official link](https://datos.imss.gob.mx/sites/default/files/glosario_datos_abiertos_asegurados_.pdf)).
Attempts on 2026-11-06 returned HTTP 403 from direct download and 503/error
responses from web retrieval. Indexed guide excerpts describe the general
open-data interface, not a verified `ptpd` codebook. No new definition or hash
for either inaccessible file is claimed. Obtain the period-specific layout and
catalogue before interpreting `ptpd` values; third-party descriptions were not
used to authorize a filter.

An attempted INEGI URL ending `enoe_2026_fd_c_bas_amp.pdf` returned non-PDF
content and was discarded as evidence. It does not establish that no official
2026 structure exists. The actual 2026 Q2 archive dictionaries support the
reviewed names and codes. Instrument vintage, reconstruction algorithms and
routing still need explicit confirmation before executable transformations.
